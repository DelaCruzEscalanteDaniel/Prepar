Correo electrónico

Con el correo configurado, el sistema envía solo las contraseñas temporales de los funcionarios, los enlaces para recuperar contraseña y los avisos.

Cómo activarlo con Gmail (gratis, 5 minutos)Sirve cualquier cuenta de Gmail, por ejemplo la del equipo.
  1. Entra a myaccount.google.com/security con la cuenta de Gmail y activa la Verificación en dos pasos.
  2. Entra a myaccount.google.com/apppasswords, escribe el nombre «Prepar» y presiona Crear. Google te muestra una contraseña de 16 letras: cópiala.
  3. Abre el archivo .env del proyecto y escribe: 
    CORREO_PROVEEDOR=gmail
CORREO_SMTP_USUARIO=tu_correo@gmail.com
CORREO_SMTP_CONTRASENA=las16letrasdegoogle
CORREO_REMITENTE=Prepar <tu_correo@gmail.com>
  4. Guarda el archivo, detén el servidor (Ctrl + C) y vuelve a arrancarlo con npm start.
  5. Regresa a esta página y presiona Enviar correo de prueba.

💡 No uses la contraseña normal de Gmail: Google la rechaza. Usa la contraseña de aplicación. El archivo .env nunca se sube a GitHub.
